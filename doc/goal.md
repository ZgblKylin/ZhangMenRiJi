做一个 Web 游戏：《掌门日记》——武侠门派经营模拟器

游戏概念：
玩家是一个新立门派的开山掌门。游戏核心循环是"以月为单位推进时间，每月做几个关键决策，门派状态随之演化"，目标是把一个三流山寨经营成名震江湖的大派。

必须包含的元素：
- 至少 3 项门派属性（如声望、银两、士气，命名要有武侠味，不要用"等级""经验值"这种游戏术语）
- 弟子系统：弟子有姓名、属性、武学专精、忠诚度，可招募、可外派、会成长也会叛逃
- 弟子行动：包括研读书籍、同门传授、切磋、打熬气血、修炼内力、外派办事、江湖历练等。
- 每月随机事件：既有「邻派挑衅」「朝廷封赏」「弟子走火入魔」这类江湖事件，也要有「米价上涨」「掌门腰疼」这类生活流事件
- 武学体系：自创至少 5 门武功
- 一个简单的「年终论剑」结算
- 存档：浏览器内可保存进度

弟子属性体系：
武学属性复刻侠客行mud的设计，即天赋属性包含膂力、悟性、根骨、身法、福源，其他常见属性包括气血、精神、内力、精力、造诣、声望、道德、门忠、年龄。
侠客行mud中的经验改成造诣，去除潜能值，消耗潜能的行动改为当前设计的基于月为单位的回合制时间消耗。

气血：
35岁前，最大气血随年龄增长。35岁后，最大气血随年龄下降。增长和下降均使用与年龄相关的固定值，而非百分比值。
可通过根骨、最大内力、奇遇、药物、特殊功法等手段提升最大气血上限。
受伤、练功、历练、切磋等行为会消耗气血值，气血值为 0 时，弟子为重伤状态，无法进行任何行动。
最大气血小于 1 时，弟子死亡。
优先参考侠客行mud的设计。

精神：
35岁前，最大精神随年龄增长。35岁后，最大精神随年龄下降。增长和下降均使用与年龄相关的固定值，而非百分比值。
可通过悟性、最大精力、奇遇、药物、特殊功法等手段提升最大精神上限。
最大精神小于 1 时，弟子死亡。
阅读、学习、冥想、修炼等行为会消耗精神值，精神值为 0 时，弟子为昏迷状态，无法进行任何行动。
优先参考侠客行mud的设计。

内力/精力：
优先参考侠客行mud的设计。

造诣：
即侠客行mud中的经验值，优先参考侠客行mud的设计。
移除潜能值，消耗潜能的行动改为当前设计的基于月为单位的回合制时间消耗。

弟子行动：
弟子每月会自动行动，门派日志中需要简略描写行动内容和成果，包括但不限于：
- 研读书籍：研读门派藏书阁有的公共书籍，和自己收集的私有书籍，能够根据悟性和武学造诣提高对应武学经验
- 同门传授：直系师长，或者关系好的同门之间传授武学
- 切磋：与同门，或者历练时遇到的随机中立/友好对象切磋武学
- 打熬气血：门内修行，提升血量上限
- 修炼内力：门内修行，提升血量上限
- 外派办事：外派处理门派事务，提升门派声望，并为门派赚取银两，时间不定，结束前无法回归门派并继续其他活动
- 江湖历练：自由发挥弟子历练过程中的遭遇，时间不定，结束前无法回归门派并继续其他活动

门派相关：
- 人员体系：根据弟子的功绩和武学考核，分为长老-内门-外门-杂役四个级别。
- 职能部门：传功、掌书、药师、司库、内勤、外务
- 门派属性：声望、库银、道德
- 门派建筑：藏经阁、银库、药库、内门仓库（其他武学相关如兵器等）、外门仓库（生活事务、外门杂物所需）等等
职能和建筑可根据具体设计要求进行调整

武学体系/战斗体系：
完整沿用侠客行的架构，如基础技能、高级技能、消耗气血打坐修炼内功、消耗精神冥想修炼精力。

- 全真派
- 天龙寺
- 桃花岛
- 少林派

- 峨嵋派
- 日月神教

国家：
沿用侠客行mud的国家设计，至少包含：
- 大元
- 大宋
- 大理
- 大夏

门派经营：
掌门每月推进月份前可以进行门派经营。所有门派经营都率属于各门派建筑的功能，包括但不限于：
- 调整每个弟子自行选择或被上级安排的本月行动
- 调整门派经营方针，会影响弟子的行动倾向
- 建造/修缮，升级门派建筑
- 人事管理（招募、调整、逐出山门）
- 物资管理（仅可发放物资给弟子）
- 门派令：消耗库银和物资颁布某项规定，在持续期间内为门派/弟子提供加成
- 藏经阁：管理门派武学典籍
- 武学研究：
  - 研究门派武学，提升门派武学造诣上限
  - 研究新武学，解锁新武学
- 门派交流：
  - 与其他门派交流，提升门派声望，提升门派关系
  - 交流过程中可能触发随机事件
  - 向其他门派请教武学，可得到对应武学典籍，消耗门派声望和银两，能够请教的武学典籍与门派关系、门派声望有关
……

触发事件：
推进月份时，除了根据每个弟子的行动决策执行行动外，还会触发各类随机事件。
在特定月份，会触发固定事件，如年终论剑。
事件触发时暂停行动更新，弹窗进入交互，交互完毕后继续推进月份。

风格要求：
- UI 必须有武侠氛围，不能是现代 SaaS 风
- 所有文案用半文半白的语气
- 弟子姓名要符合武侠习惯

性能要求：
由于所有NPC门派的弟子和本门弟子每月都会自动行动，且每月会触发随机事件，游戏需要在浏览器中流畅运行，不能出现明显卡顿。
回合推进时，采用快照+并行计算的方式，基于上月的快照状态，并行计算每个弟子的行动。
弟子行动均基于上月的状态快照进行计算，以避免数据竞争和计算顺序问题。
涉及到弟子之间的交互行为时，需要将参与人员合并进行计算，避免出现数据依赖和计算顺序问题。
涉及到门派属性、资源的变更时，各弟子行动可独立计算，在所有人物行动计算完毕后再统一更新门派属性和资源，避免出现数据依赖和计算顺序问题。

交付要求：
- 至少能完整玩通 24 个月（两届论剑）
