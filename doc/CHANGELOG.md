# 《掌门日记》更新日志

## v3.2.0（2026-07-19）—— 数值平衡与长期稳定性

### 寿命与修炼

- **寿命曲线重调**：35-60岁设为壮年平台，60岁起逐年衰减；每百点内力/精力推迟衰老一岁，常人约百岁，宗师可逾两百岁
- **修炼难度渐增**：打坐/冥想的收益随当前值逼近上限递减，修炼越深进展越缓，无奇遇丹药时几乎不可能永生
- **具名NPC保护**：金庸小说人物的气血/精神下限恒为1，衰老不致死亡，最多重伤归隐，确保小说架构稳定

### 门派经营

- **庶务堂等级约束**：其他建筑扩建等级不得超过庶务堂，NPC AI亦遵守此限
- **草药消耗平衡**：NPC门派草药充裕时自动多炉炼丹，避免库存无限堆积

### 门派交互

- **边境冲突强化**：弱势方堂舍受损、银两粮秣被掠
- **背盟惩罚加深**：受害方堂舍受损、药材粮秣被盗
- **合纵连横机制**：声望远超同侪的强势门派会触发相邻弱派自动结盟制衡

### 测试

- 新增60回合长期稳定性测试：验证人口循环、建筑上限、国势边界与资源约束
- 被忽略的24回合综合可达性测试修复为常规测试
